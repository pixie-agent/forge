# Support

## Community support

Use GitHub issues for reproducible bugs and feature requests. Before opening an issue, remove secrets, tokens, user data, project IDs that should remain private, and production logs containing customer content.

This public repository does not provide an SLA. Support for a separately licensed commercial deployment is governed by its written commercial agreement.

## Security reports

Do not report vulnerabilities or leaked credentials in a public issue. Follow [SECURITY.md](SECURITY.md).
