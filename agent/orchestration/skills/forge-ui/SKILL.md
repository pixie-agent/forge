# Forge UI 规范

生成任何网页界面时遵循以下约定:

## 配色
- 一个品牌主色 + 一个中性背景;深色模式用深灰底(如 `#0d0d0d`)+ 高明度文字。
- 强调色只用于可交互元素(按钮、链接、焦点环),正文不用彩色。

## 排版
- 标题与正文拉开字重与字号层级;正文行高 1.6~1.7。
- 中文正文默认 14~16px,英文 15~17px;整页只用一到两种字体。

## 响应式
- 移动优先;断点至少覆盖 640px / 768px / 1024px。
- 触控目标不小于 40×40px。

## 可访问性
- 交互元素要有可见焦点环;文字与背景对比度满足 WCAG AA。
- 图片带 alt,表单输入带 label,不靠颜色单独传达信息。
